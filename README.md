# Homebrew Liferay

A centralized repository for Liferay-related brews.

## Requirements

- [Homebrew](https://brew.sh)

## Adding the tap

```sh
brew tap david-truong/liferay
```

Homebrew strips the `homebrew-` prefix from tap names, so the tap is referenced as `david-truong/liferay`.

## Installing formulas

Once the tap is added, install any of the available formulas:

```sh
brew install david-truong/liferay/blade
brew install david-truong/liferay/gw
brew install david-truong/liferay/liferay
brew install david-truong/liferay/liferay-issues-cli
```

## Updating

```sh
brew update
brew upgrade <formula>
```

## Removing the tap

```sh
brew untap david-truong/liferay
```
